# 営業支援ツール（Sales Automation Tool）

お問い合わせフォームへの**自動送信**を中心に、**企業リスト管理（軽量CRM/SFA）**・
**文面テンプレート**・**KPI計測**をひとつにまとめた Web ダッシュボードです。
打ち合わせで合意したKPI（**担当者接続率 15%以上 / アポイント率 1%以上**）を
そのまま画面上で可視化します。

> 表向きは「営業の生産性向上・コスト削減ツール」として提示でき、"AI" を全面に
> 出さない設計です（フォーム解析エンジンは LLM へ差し替え可能な構造）。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 📊 ダッシュボード | 登録企業数・送信回数/成功・**担当者接続率**・**アポイント率**を目標値と色で表示。ステータス内訳のバー表示 |
| 🏢 企業リスト（軽量CRM/SFA） | 企業の追加/編集/削除、**一括インポート**（CSV/TSV貼り付け）、営業ステータス管理（未送信→送信済→接続→アポ獲得→見送り） |
| ✉️ フォーム自動送信 | テンプレート×送信先を選んで一括送信。フォーム構造を自動解析して対応欄へ入力・送信。**送信後のスクショ記録**。ドライラン対応 |
| 📝 文面テンプレート | 変数差し込み（`{{company}}` `{{fullName}}` `{{target}}` など）付きテンプレートの作成・管理 |
| 🕘 送信履歴 | 送信ごとの検出項目数・入力項目数・成否・キャプチャを一覧 |
| ⚙️ 送信者設定 | フォームに自動入力する自社情報（会社名・氏名・連絡先など） |

## 使い方

```bash
cd sales-tool
npm install
npm start            # http://localhost:4180 を開く
```

初回起動時にデモ用データ（サンプル企業3社・テンプレート2種）が自動投入されます。
デモ用の疑似企業サイト（`/targets/company-a` 〜 `c`）が同梱されているため、実在企業へ
送信せずに自動送信の一連の流れを試せます。

### デモ動画の生成

```bash
npm run demo         # ダッシュボード操作〜自動送信を録画 → demo.mp4 / shots/*.png
```

## アーキテクチャ

```
sales-tool/
├─ server.js              # APIサーバー（CRUD・送信実行・KPI集計）＋ 静的配信
├─ src/
│  ├─ db.js               # JSONデータストア（data/db.json）。本番はDBへ差し替え可
│  ├─ field-mapper.js     # フィールド解析エンジン（どの欄に何を入れるか判定）
│  ├─ sender.js           # Playwrightによるフォーム自動入力・送信
│  └─ mock-targets.js     # デモ用 疑似企業サイト（3社）
├─ public/                # ダッシュボード（HTML/CSS/JS・依存ライブラリなし）
└─ scripts/demo-run.js    # デモ録画オーケストレーター
```

### フォーム解析について（AI差し替えポイント）

企業ごとに構造が異なるフォームを汎用的に扱うため、`src/field-mapper.js` が
各入力欄の意味（会社名・氏名・メール・本文…）を推定します。現状はキーワード
スコアリングのルールベースですが、入出力を保ったまま `classifyField()` を
LLM 呼び出しに置き換えることで、より複雑なフォームにも対応する本番版へ移行できます。

## KPI計算式

- **到達率** = フォーム送信成功数 ÷ 送信回数
- **担当者接続率** = （接続 + アポ獲得）÷ 送信済企業数　… 目標 **15%以上**
- **アポイント率** = アポ獲得 ÷ 送信済企業数　… 目標 **1%以上**

「接続」「アポ獲得」は電話フォローの結果として企業リストのステータスを更新すると、
ダッシュボードへ即時反映されます。

## 注意事項

実在企業のフォームへ送信する場合は、各サイトの利用規約・特定電子メール法・個人情報の
取り扱い等を遵守してください。本ツールはPoC/デモ用途を前提としています。
