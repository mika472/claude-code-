# 採用支援ツール（Recruiting Suite）

**AIによる求人原稿の自動作成**を中心に、**応募者管理（軽量ATS）**・**応募者対応文面の自動生成**・
**採用KPI/コスト計測**をまとめた Web ダッシュボードです。打ち合わせで挙がった
「求人広告の自動作成」「応募者対応のAI化」「保育士など業界特化」「採用コスト削減」に対応します。

> 営業支援ツール（`../sales-tool`）と同じ作り・同じ操作感。表向きは「採用業務の効率化ツール」として
> 提示でき、生成エンジンが AI であることを前面に出さずに使えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 📊 採用ダッシュボード | 公開求人数・総応募数・内定/入社・**採用単価**（媒体費÷入社数）・**応募単価**を可視化。選考ステータス／応募チャネル別の内訳 |
| ✨ AI求人作成 | 職種・業種・条件を入力 → 求人原稿（キャッチコピー＋本文）を自動生成 → 編集して保存。業種特化（保育/介護/IT/営業 等） |
| 📋 求人一覧 | 求人の一覧・本文表示・公開ステータス管理（下書き/公開中/終了）・応募者数 |
| 👥 応募者管理（軽量ATS） | 応募者の追加/編集/削除、選考パイプライン管理（応募→書類選考→面接→内定→入社→見送り）、チャネル記録 |
| ✉️ 応募者対応の自動化 | 応募者ごとに「応募お礼／面接案内／内定通知／お見送り」の文面をAIで生成 |
| ⚙️ 会社情報・予算 | 求人に使う会社情報と、採用単価算出に使う媒体費（採用予算） |

## AI生成について（Claude）

求人原稿・応募者対応文面の生成は **Claude（`claude-opus-4-8`）** を使用します。

- 環境変数 `ANTHROPIC_API_KEY` が設定されていれば **Claude API（`@anthropic-ai/sdk`）で生成**します。
- 未設定の場合は **ルールベースのテンプレート生成にフォールバック**するため、APIキーなしでも動作します
  （デモ・オフライン環境向け）。サイドバーに現在のモード（AI生成/テンプレート）を表示します。

実装は `src/job-generator.js` / `src/reply-generator.js`。AI呼び出しに失敗した場合も必ずテンプレートで
結果を返すため、採用担当の作業が止まりません。

## 使い方

```bash
cd recruit-tool
npm install
# AI生成を使う場合のみ:
export ANTHROPIC_API_KEY=sk-ant-...
npm start            # http://localhost:4190 を開く
```

初回起動時にデモ用データ（求人2件・応募者6名・媒体費）が自動投入されます。

### デモ動画の生成

```bash
npm run demo         # ダッシュボード〜AI求人作成〜応募者対応を録画 → demo.mp4 / shots/*.png
```

## アーキテクチャ

```
recruit-tool/
├─ server.js               # APIサーバー（CRUD・生成・KPI集計）＋ 静的配信
├─ src/
│  ├─ db.js                # JSONデータストア（data/db.json）。本番はDBへ差し替え可
│  ├─ job-generator.js     # 求人原稿生成（Claude or テンプレート）
│  └─ reply-generator.js   # 応募者対応文面生成（Claude or テンプレート）
├─ public/                 # ダッシュボード（HTML/CSS/JS・依存ライブラリなし）
└─ scripts/demo-run.js     # デモ録画オーケストレーター
```

## KPI計算式

- **内定率** = （内定 + 入社）÷ 総応募数
- **採用単価** = 媒体費（採用予算）÷ 入社数　… 採用コスト削減の主要指標
- **応募単価** = 媒体費 ÷ 総応募数

媒体費は「会社情報・予算」画面で設定します。応募チャネルを記録すると、どの媒体からの応募が多いかも
ダッシュボードに表示されます。

## 注意事項

生成された求人原稿・メール文面は、送信・掲載前に必ず内容をご確認ください。労働条件の表示は
職業安定法・労働基準法等の関連法令に従ってください。本ツールはPoC/デモ用途を前提としています。
